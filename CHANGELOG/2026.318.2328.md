# 2026.318.2328 — feat(whisper): serve an OpenAI-compatible STT endpoint for cross-pod discovery

## Summary

`openai/whisper` ships **no HTTP server** — measured at `v20250625`: the whole tree is 45 files with zero matches for any web framework, any route decorator, and `audio/transcriptions`. So this candy now owns the wire surface, and it owns it as a **service** rather than a CLI wrapper.

What the candy becomes:

- **`app.py`** — a charly-owned FastAPI app that loads the checkpoint **once** (`whisper.load_model`) and calls `model.transcribe` in-process. The `whisper` CLI is deliberately not used per request: it reloads the checkpoint on every invocation and writes five basename-colliding output files into the CWD.
  - `POST /v1/audio/transcriptions` (multipart `file`, optional `model`/`language`) → JSON with a **top-level `text`**, which is the only field Open Web UI reads.
  - `GET /health`, `GET /v1/models`.
  - Optional bearer auth — **401** when a key is configured, and an explicitly logged open posture when it is not (the posture is stated, never inherited).
  - A model this server does not serve is a **400 naming both**, never a silent substitution.
  - Uploads are size-capped and decoded from a private temp path.
- **`service: whisper-asr`** — a **charly-owned start script** written by the candy: it prefetches the checkpoint **onto the volume before** `uvicorn` binds, so a first user request never pays for a download inside Open Web UI's 300 s STT budget.
- **`env_provide: WHISPER_BASE_URL: http://{{.ContainerName}}:9000/v1`** — product-scoped, matching every other provide in the org (`OLLAMA_HOST`, `QDRANT_URL`, `STRATA_BASE_URL`, …). The `/v1` is part of the contract: Open Web UI appends `/audio/transcriptions`.
- **Eight deploy-time knobs** (`env_accept`): model, device, fp16, language, task, beam size, port, upload cap; plus `secret_accept: WHISPER_API_KEY` (`charly/api-key/whisper`).
- **`port: 9000`**, **`volume: whisper-models → ~/.cache/whisper`**.
- **Three `check:` steps**: health, an OpenAI-shaped model list, and a real transcription of a committed fixture.
- **`fixtures/jfk.flac`** (1 152 693 bytes, `sha256 63a4b1e4…`, from `openai/whisper` `tests/jfk.flac@v20250625`, provenance in `fixtures/README.md`) — the check asserts the word pair **"fellow Americans"**, a property of the audio rather than of a model, so the assertion proves the *service*.

Also in this PR: `fastapi`/`uvicorn`/`python-multipart` added to the pixi env (lock regenerated with pixi 0.70.2; Python stays 3.14.5 and `openai-whisper` stays `20250625`), the `require:` pins advanced to current tags, and **`layer-cuda` dropped** (see Rulebook compliance, R5).

was re-run to prove the other side (21/21, 0 skipped).

## Change classification

**Breaking change + rollback:** the candy stops being CLI-only and starts a service on port 9000; any consumer that composed it for the CLI alone now also gets a listener (additive, but it binds a port) and `layer-cuda` is no longer composed (images that relied on the transitively-provided CUDA toolkit must name it themselves). Rollback is a revert of this PR plus a re-pin — the volume is additive (weights survive) and no data is migrated.
