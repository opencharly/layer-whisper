# 2026.328.1901 — docs(whisper): the HOME check guards the model-cache path, not a keep-id root HOME

## Summary

The comment above the whisper candy's `HOME` check described the wrong mechanism. A bound whisper pod carries **no CDI device**, so its bind selects `keep-id` with the image user (uid 1000), where `HOME` is already `/home/user` — the container-root shape (whose `HOME` is `/root`) requires a CDI device and does not exist for this candy. The check is therefore a guard on the **model-cache path** (`$HOME/.cache/whisper`, which must live in the bound home), not a user-namespace discriminator, and the comment now says so.
